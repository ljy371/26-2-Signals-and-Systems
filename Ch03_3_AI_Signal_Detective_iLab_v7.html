3.7 IMPULSE RESPONSE
Why detect a Double Tap?실생활 응용 · 스마트폰 뒷면 두드리기

스마트폰 뒷면을 두 번 두드리면 스크린샷을 찍는 기능을 생각해 봅시다. 뒷면에 별도의 물리적 버튼이 없어도 스마트폰은 내부 센서의 가속도 변화를 이용해 두드림을 감지할 수 있습니다.

하지만 걷거나 스마트폰을 내려놓을 때도 충격이 발생합니다. 어떻게 하면 사용자가 의도한 두 번의 두드림과 흔들림을 구별할 수 있을까요?

이번 실습: 가속도 x[n] → 학습형 FIR의 Convolution → Double Tap 점수 → 명령 실행 여부 판단
실제 휴대전화의 모든 구현이 이와 동일한 알고리즘을 사용하는 것은 아닙니다. 이 HTML은 원리를 설명하는 교육용 합성 센서 데이터와 작은 분류기를 사용합니다.
How does Train AI actually learn?
Target label: Double Tap = 1Bias b = 0.000Epoch 0
MODEL & LEARNING TARGET25-tap causal FIR + bias + sigmoid
① Linear FIR + biasz[n] = Σk=024 w[k]x[n−k] + b
② Binary classificationP[n] = σ(z[n])
③ Parameters to learnθ = {w[0], …, w[24], b}25 FIR weights + 1 bias = 26 unknowns

학습 목표: Label t(더블탭=1, 기타=0)와 예측 확률 P의 차이를 나타내는 Binary Cross-Entropy (BCE)를 줄이도록 26개의 파라미터를 찾습니다. 정답은 가속도의 크기가 아닌 패턴의 종류입니다.

선형 FIR 부분의 Impulse Response는 h[k] = w[k]입니다. 다만 bias와 sigmoid를 포함한 전체 분류기는 LTI 시스템이 아닙니다.
What is 1 epoch?학습 데이터 280개(더블탭 140 + 기타 140)를 모두 한 번씩 사용하여 SGD로 계수를 갱신하는 1회 전체 순회입니다. 40 epochs이면 이 280개 데이터셋을 40회 반복합니다. 별도 테스트 데이터 160개는 가중치를 학습하는 데 사용하지 않습니다.
What is learned?

필터의 시간별 가중치 w[0]~w[24]와 출력 기준을 조절하는 bias b를 학습합니다.z[n] = Σ w[k]x[n−k] + b

How is the decision made?

가중합 z[n]을 sigmoid에 통과시켜 확률처럼 해석합니다.P[n] = σ(z[n])

What does training do?

정답 t와 예측 P의 BCE를 줄이도록 경사하강법(SGD)으로 w[k], b를 조금씩 업데이트합니다.w ← w − η∂L/∂w

학습 전에는 w[k]=0, b=0 → P=0.5입니다. 아래 그래프와 학습 데이터 예측값을 비교해 보세요.

PART 04 · STABILITY IN THE PHYSICAL WORLD

Experiment A · Small sensor bias accumulates over time

스마트폰이 정지해 실제 가속도가 0이더라도, 센서가 작은 일정한 Bias x[n]=0.1을 갖는다면? 동일한 입력을 일반 누적기와 감쇠 누적기에 넣어 봅니다.

Accumulator · a=1 y[n] = y[n−1]+x[n]
h[n] = u[n],   y[n] = 0.1(n+1)
Leaky Filter · a=0.8 y[n] = 0.8y[n−1]+x[n]
h[n] = 0.8ⁿu[n],   y[n] → 0.5
Identical bounded sensor bias → different outputs
Blue · AccumulatorGreen · Leaky
작은 일정 입력도 계속 누적되면 출력은 증가합니다. 불안정성은 계수를 무조건 크게 설정해서만 발생하는 현상이 아닙니다. 경계값 a=1인 적분(누적) 시스템에서도 발생합니다.

Experiment B · Both x[n] and h[n] are bounded. Why does y[n] diverge?

a=−1이고 x[n]=(−1)ⁿ, h[n]=(−1)ⁿu[n]이라면 두 신호의 크기는 항상 1 이하입니다. 그러나 Convolution의 곱이 모두 같은 부호로 더해집니다.

n=0n=12
Input x[k]
Time-reversed h[n−k]
Product x[k]h[n−k]
n=4: 다섯 개 항이 모두 양수이므로 y[4]=5
y[n] = Σk=0n (−1)k(−1)n−k = (n+1)(−1)n
BIBO 핵심: h[n]이 유계라는 사실만으로 충분하지 않습니다. Σ|h[n]| < ∞이어야 모든 유계 입력에 대해 y[n]도 유계가 됩니다. 여기서는 Σ|h[n]| = 1+1+1+⋯ = ∞입니다.

Noise reduction is not the same as recognizing a gesture.

Part 01에서 해결한 문제: Moving Average(FIR)와 Exponential Smoother(IIR)는 충격 응답의 높이와 지속 시간을 바꾸며 노이즈를 줄일 수 있습니다.

아직 남아 있는 문제: 스마트폰을 두 번 두드리는 동작뿐 아니라 걷기·흔들림·한 번의 충격도 센서 피크를 만듭니다. 평균화만으로 의도적인 Double Tap과 다른 움직임을 자동 구별하도록 설계된 것은 아닙니다. 전통적인 규칙 기반 검출도 가능하지만 간격과 형태의 기준을 직접 정해야 합니다.
